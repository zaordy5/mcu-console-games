# Одиночный пинг-понг

В сборнике выберите `3. Pong`, затем `1` (Easy), `2` (Normal) или `3` (Hard).
Левая ракетка — ваша, правая — компьютера. `W` двигает ракетку вверх, `S` — вниз.
`Q` возвращает в общее меню из матча и с экрана результата. Enter не требуется,
регистр букв не важен.

Матч идёт до 5 очков. После промаха показывается новый счёт, позиции сбрасываются
и через 600 мс начинается следующая подача. Направление подачи чередуется.
Попадание в верхнюю или нижнюю часть ракетки меняет направление отскока
по вертикали, попадание в центр даёт горизонтальный отскок.

После победы `N` начинает матч следующего уровня на той же сложности со счётом
0:0. На последнем уровне L10 и после поражения используйте `Q`. Выбор Pong
из меню всегда начинает новую сессию с L1 и счётом 0:0.

Компьютер перемещается на одну клетку раз в 400 мс на Easy, 240 мс на Normal
и 175 мс на Hard. На L1 мяч проходит клетку за 90 мс, на L2 — за 84 мс,
на L10 — за 36 мс. При большом интервале между вызовами `tick` мяч проходит
каждую клетку по отдельности, поэтому контакт с ракеткой проверяется и на L10.
Для цветного экрана нужен ANSI-терминал с областью хотя бы 42 × 21.

## Проверки на ПК

Из корня репозитория, GCC 14.2.0.

```sh
cc -std=c11 -Wall -Wextra -Werror -pedantic -Isrc \
  src/pong_core.c tests/pong_core_test.c -o /tmp/pong-core-test
/tmp/pong-core-test
```

Проверяются границы обеих ракеток, отскоки от двух стенок, края и центра ракетки,
контакт на максимальной скорости, промах и однократное начисление очка,
следующая подача, победа и поражение, переход уровня и одинаковый результат
при передаче времени одним интервалом или шагами по 1 мс. Тест выводит измеренные
интервалы движения CPU и мяча.

Для проверки адаптера нужен `include/game.h` из #5. Если #5 ещё не влит, можно
передать путь к его каталогу `include` через переменную `GAME_INCLUDE`.

```sh
cc -std=c11 -Wall -Wextra -Werror -pedantic -Iinclude -I"${GAME_INCLUDE:-include}" \
  src/pong.c src/pong_core.c tests/pong_game_test.c -o /tmp/pong-game-test
/tmp/pong-game-test
```

Тест перехватывает `console_write` и проверяет цвета, выбор сложности, обе
клавиши движения, результат, `N` после победы, `Q` и сброс при новом запуске.

## Подключение к сборнику

Платформа и `Game` приходят из #5. В рамках #4 нужно подключить
`include/pong.h` и зарегистрировать `&pong_game` в слоте 3, добавить
`src/pong.c` и `src/pong_core.c` в цель `games` и передавать в
`Game.start` выбранное `GameDifficulty`. В общей UART-проверке следует
проверять меню сложности и экран Pong вместо экрана-заглушки. Экран матча
рисует сам модуль.

### Проверка в Renode 1.17.0 после подключения

```sh
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=cmake/arm-gcc.cmake
cmake --build build
renode
```

В Renode Monitor укажите абсолютные пути.

```text
set bin @/путь/к/репозиторию/build/games.elf
include @/путь/к/репозиторию/emulation/stm32f4.resc
start
```

В USART2 нажмите `3 1 W s` до первой подачи, между нажатиями дайте экрану
обновиться. Если после этого не двигать ракетку, примерно через 22 секунды
виртуального времени появляется `You win!` со счётом 5:4. Нажмите `n`
для старта L2 с 0:0, затем `q` для возврата. Снова нажмите `3 3 Q`
и проверьте, что новый матч Hard открылся на L1 с 0:0 и вернулся в меню.

### Автоматическая проверка USART2

На Linux после сборки общего ELF запустите следующую команду с Python 3 и
Renode 1.17.0 в PATH.

```sh
python3 tests/pong_renode.py build/games.elf
```

Можно указать путь к Renode через `--renode`, а каталог логов через
`--output`. По умолчанию вывод Monitor и байты USART2 сохраняются в
`build/pong-check/renode.log` и `build/pong-check/pong.uart`.

Сценарий отправляет клавиши через `sysbus.usart2 WriteChar` без Enter.
Он проверяет четыре ANSI-цвета и следующие события в порядке их появления.

| Клавиши | Что проверяется |
|---|---|
| `3 1 W s`, пауза, `n q` | Движение ракетки в обе стороны, победа 5:4, переход на L2 с 0:0, возврат в меню |
| `3 3 Q` | Hard открывается на L1 с 0:0, Q возвращает в меню из текущего матча |
| `3 Q` | Q отменяет выбор сложности |
| `3 2`, пауза, `Q` | Normal открывается на L1, появляется поражение 0:5, Q возвращает в меню с экрана результата |
