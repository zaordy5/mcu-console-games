## Опись

| Материал | Что проверять |
| --- | --- |
| Исходники и история Git | Открываются все каталоги и конфигурации. История доступна проверяющему. Для передачи вне GitHub подойдёт `git bundle` выбранной ветки из полной копии репозитория. |
| `commit.txt`, `build.log`, `games.elf`, `games.resc` | SHA исходников, команды сборки, контрольная сумма ELF и запуск прошивки в Renode. |
| `main-menu.png`, `difficulty.png`, `menu-check/menu.uart`, `tetris.uart`, `pong-check/pong.uart` | Меню, три игры, сложности, уровни, возвраты и цветная консоль. |
| `doxygen-report` | HTML, лог и XML-индексы для проверки охвата комментариев. |
| Независимая сборка | SHA, ОС, версии CMake и Arm GCC, команды, полный лог и вывод Renode со стороннего компьютера. |
| `demo-games.mp4`, `demo-gdb.mp4` | Если ролики ещё готовятся, ориентир — [сценарий записи](VIDEO.md). Для готовых видео укажите таймкоды и SHA использованного ELF в описи. |
| Фото или видео платы, видео SWD/JTAG | Отдельные материалы для П1 и П8. Статус в [задаче №4](https://github.com/zaordy5/mcu-console-games/issues/4). |

Скачайте архивы `firmware-menu` и `doxygen-report` из прогона, соответствующего SHA сдачи. Храните копии рядом с исходниками и записями. Ссылки на артефакты GitHub Actions имеют ограниченный срок действия.

Перед отправкой соберите проект из передаваемой копии по [инструкции](INTEGRATION.md), откройте вложения и проверьте доступ жюри к приватному репозиторию и файлам.
