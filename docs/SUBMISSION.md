## Порядок воспроизведения

1. Получить полный архив исходников или Git-репозиторий. Переключиться на указанный SHA, проверить `git rev-parse HEAD`, собрать с чистым каталогом `build` по [INTEGRATION.md](INTEGRATION.md). Записать ОС, версии GCC, CMake и Renode, команду и результат `arm-none-eabi-size`, полный лог и SHA-256 своего ELF. Контрольные суммы ELF разных сборок могут отличаться.
2. Для запуска CI-архива извлечь `games.elf` и `games.resc` в одну папку. В Renode Monitor выполнить `include @C:/mcu-games/games.resc` с фактическим абсолютным путём, затем `start`. Окно USART2 — ANSI RGB, минимум 80×24. Выполнить маршрут `1` → сложность → Тетрис → `Q`, затем аналогично `2` и `3`. В конце повторно открыть Тетрис. Проверить возобновление Сапёра по `U`.
3. Запустить четыре проверки Renode по [INTEGRATION.md](INTEGRATION.md). CI базы QA проверил Linux с пробелами в `TMPDIR`. Проверить Doxygen по той же инструкции.
4. После приёмки изменений выбрать один SHA сдачи. Повторить CI, независимую сборку и привязать видео, журналы и снимки к этой ревизии. Указать SHA исходников и SHA-256 демонстрационного ELF на записи или в описи. Проверить доступ жюри к репозиторию и архивам. Ссылки GitHub Actions имеют срок действия, поэтому сохранять копию утверждённого комплекта.
