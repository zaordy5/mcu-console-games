# Падающие блоки · задача #1

Партия идёт на поле 12 × 18. Семь форм из трёх, четырёх и пяти клеток получают свой цвет. В каждом наборе каждая форма выпадает один раз в перемешанном порядке. Новая партия начинается с пустого поля и той же последовательности форм для воспроизводимых проверок.

| Клавиша | Действие |
|---|---|
| A / D | Сдвинуть фигуру влево / вправо на клетку |
| W | Попробовать повернуть фигуру по часовой стрелке |
| S | Ускорить падение на один ряд, заново запустив отсчёт до следующего автоматического шага |
| Q | Вернуться в меню во время партии или с экрана результата |

Клавиши работают в обоих регистрах, Enter не нужен. При столкновении поворот отклоняется, фигура остаётся на месте. Если очередной шаг вниз заблокирован, фигура закрепляется. Все полные строки удаляются одновременно, остальные сдвигаются вниз. Когда новая фигура не помещается сверху, остаются итоговые счёт и уровень. Нажми Q для возврата.

| Сложность | Первый уровень | Второй уровень |
|---|---:|---:|
| Easy | 850 мс/ряд | 780 мс/ряд |
| Normal | 600 мс/ряд | 530 мс/ряд |
| Hard | 350 мс/ряд | 280 мс/ряд |

Уровень начинается с 1 и повышается каждые 5 очищенных строк. Каждый переход уменьшает интервал автоматического падения на 70 мс, до минимума в 100 мс. Если за одно закрепление удалено N строк, счёт увеличивается на 100 × N². На экране видны сложность, счёт, уровень, число строк и текущий интервал.

## Проверка на ПК

Из корня репозитория. Нужны GCC с поддержкой C11 и оболочка POSIX.

```sh
out="$(mktemp -d)"
gcc -std=c11 -O2 -Wall -Wextra -Wconversion -Werror -pedantic -Iinclude \
  src/tetris_core.c tests/tetris_core_test.c -o "$out/tetris_core_test"
"$out/tetris_core_test"
```

Тесты создают воспроизводимые позиции для стен, дна и занятых клеток, проверяют закрепление, очистку одной, двух несмежных и трёх смежных строк, проигрыш и сброс. Проверка таймера наблюдает первый шаг на 350, 600 и 850 мс и шаг на ускоренном интервале после пятой линии.

Для теста обратных вызовов нужен `include/game.h`. Пока платформа в [PR #5](https://github.com/zaordy5/mcu-console-games/pull/5), проверенный заголовок можно извлечь из его коммита. Команды продолжают предыдущий блок.

```sh
game_include=include
if [ ! -f include/game.h ]; then
  git fetch origin refs/pull/5/head
  mkdir "$out/pr5"
  git show 9d2444e4e25a5ed0fa2417125bf5da248e4b1041:include/game.h > "$out/pr5/game.h"
  game_include="$out/pr5"
fi
gcc -std=c11 -O2 -Wall -Wextra -Wconversion -Werror -pedantic \
  -Iinclude -I"$game_include" src/tetris_core.c src/tetris.c tests/tetris_game_test.c \
  -o "$out/tetris_game_test"
"$out/tetris_game_test"
```

Тест захватывает вывод `console_write` и проверяет цветовые команды ANSI, обработку клавиш, обновление поля без очистки всего экрана, ожидание Q после проигрыша и чистый старт следующей партии.

## Подключение к прошивке

Игровые правила находятся в `src/tetris_core.c`, адаптер `Game` и отрисовка — в `src/tetris.c`. Для подключения после [PR #5](https://github.com/zaordy5/mcu-console-games/pull/5) добавь оба исходника в цель `games` и зарегистрируй `&tetris_game` из `include/tetris.h` в первом пункте меню. Выбранную сложность передай в `start`. Партия рисует экран через `draw`, а `finished` сообщает меню о нажатии Q. Изменения общего меню, выбора сложности и сценария UART согласуются в [#4](https://github.com/zaordy5/mcu-console-games/issues/4).

После подключения собери ELF из корня проекта.

```sh
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=cmake/arm-gcc.cmake
cmake --build build
renode
```

В Renode 1.17.0 укажи абсолютные пути к ELF и сценарию, затем запусти модель.

```text
set bin @/absolute/path/mcu-console-games/build/games.elf
include @/absolute/path/mcu-console-games/emulation/stm32f4.resc
start
```

В терминале USART2 выбери первый пункт меню и начни партию на Easy. Проверь A, D, W и S, затем нажми Q и проверь возврат. Открой игру на Hard и нажимай S без сдвигов до надписи `Game over.`. Нажми Q и повторно зайди в игру. На новом экране должны быть пустое поле с первой фигурой, счёт 0 и уровень 1.
